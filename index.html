Welcome to eyesunstrung

TL;DR: it's a website dedicated to screen-reader-accessible material to learn about music and playing guitar, and hosts an accessible web-based application to use song files and tools for skills development.

For details, read the Introduction to eyesunstrung article. The About page has some personal and technical details if you're curious about the eyesunstrung name, the .vip domain choice, or how the site is developed and hosted.

The unstrung Application

As explained in the introduction, the main point of eyesunstrung.vip is to host the web-based version of the unstrung application. Hopefully all your questions will be answered in the unstrung pages. All documentation is structured with screen reader users in mind. Common semantic HTML navigation techniques are supported (e.g., landmarks, headings, lists, anchors).

Articles

Also mentioned in the introduction, eyesunstrung hosts articles about music and guitar. What's there is what I think is interesting and hopefully useful to others. The root articles page has a small blurb about each article. Each blurb has a heading which is also a link to the article, it should be very screen reader friendly.

Requests, Comments, and Feedback

For general feedback on the eyesunstrung.vip site or the unstrung application, web or desktop, please email feedback at eyesunstrung.vip.

Anything specific to the site or the app can also go in the eyesunstrung GitHub issues or the unstrungApp GitHub issues.
